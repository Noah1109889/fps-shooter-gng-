# Breach Protocol

An original browser-based tactical FPS-inspired prototype. It is **not affiliated with or a reproduction of Rainbow Six Siege** and uses original operator names, mechanics, visuals, and UI.

## Play

Open `index.html` in a modern browser. Choose an operator, then use:

- **WASD** — move
- **Mouse** — aim
- **Left click** — fire
- **Space** — deploy your operator gadget
- **R** — reload
- **Esc** — pause

The current prototype is a top-down tactical sandbox with line-of-sight, cover, enemy AI, weapon heat, gadget charges, breach points, and a round timer. It is dependency-free and ready for GitHub Pages.
